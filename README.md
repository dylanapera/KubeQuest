# KubeQuest
A basic Azure Kubernetes Service (AKS) application designed to demonstrate container orchestration using pure Azure-based services.

## What You Need to Know
- Language/Framework: Python
- Containerization: Docker image pushed to ACR
- Cluster Setup: AKS cluster provisioned via Portal
- Networking: Basic Azure networking 
- Authentication: Entra ID integrated for secure access

## Azure Services Used
- Azure Kubernetes Service (AKS)
- Azure Container Registry (ACR)
- Azure Monitor
- Azure Networking

## Ready To Go?
Attempt to all missions. Start with Mission 1 through to 6. By the end of this you should be able to deploy your first AKS application.

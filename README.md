# KubeQuest
A basic Azure Kubernetes Service (AKS) application designed to demonstrate container orchestration using pure Azure-based services.

## What You Need to Know
- Language/Framework: Python
- Containerization: Docker image pushed to ACR
- Cluster Setup: AKS cluster provisioned via Portal
- Networking: Basic Azure networking 
- Authentication: Entra ID integrated for secure access

## Azure Services Used
- Azure Kubernetes Service (AKS)
- Azure Container Registry (ACR)
- Azure Monitor
- Azure Networking

## Ready To Go?
### Mission 1: Understand the basics
#### What is AKS?
- Azure Kubernetes Service is a managed Kubernetes offering for container orchestration.
#### Key Concepts:
- Cluster: A group of nodes running your workloads.
- Node: A VM that runs containers.
- Pod: The smallest deployable unit in Kubernetes.
#### Why AKS?
- Simplifies Kubernetes setup, integrates with Azure services, and scales easily.
